## Input and output

Every request contains exactly seven fields. Numeric bounds are rainfall 600–1400 mm, temperature 12–26 °C, soil moisture 20–80%, fertilizer 0–250 kg, and field size 0.2–4.0 ha. `season` is `A` or `B`; `cooperative_support` is integer 0 or 1. Missing, null, extra, string-encoded numeric, non-finite, and out-of-range values are rejected.

```bash
curl -s -X POST http://127.0.0.1:8000/predict \
  -H 'Content-Type: application/json' \
  -d '{"rainfall_mm":950.0,"avg_temp_c":18.0,"soil_moisture_pct":55.0,"fertilizer_kg":90.0,"field_size_ha":1.5,"season":"A","cooperative_support":1}'
```

The response includes the verification code, estimated yield, binary high-risk estimate, class-1 probability, cluster ID, and `synthetic_prototype: true`. `/health` confirms saved models are loadable; `/model-info` exposes model selections, feature order, fingerprint, versions, and limitations. Prediction never retrains.

## Reproducibility and leakage controls

The generator uses one `numpy.random.default_rng(seed)`, the prescribed distributions and formula, a median computed on original base records, planned missingness, three exact duplicate rows, four-decimal CSV output, and a SHA-256 of final bytes. Cleaning removes duplicates only. A single stratified split is shared by every task. Imputation, scaling, and encoding live inside fitted pipelines and learn only from training rows. Yield, yield per hectare, risk labels, and row IDs are never model inputs.

Artifacts contain all baseline/candidate comparisons, CV selection evidence, held-out predictions, error examples, K=2..6 silhouettes, cluster profiles, and plots. Models are local joblib files and should be loaded only from this trusted project.

The current personal build uses 280 base rows, 283 raw rows and 280 cleaned rows. Its CSV SHA-256 is `ffb9be9b7e281791dc2143236fbb19a067ff3bf5e793b535f90b2b280ed149d4`. Training-only validation selected Ridge regression, Random Forest classification and K=2 clustering. These values are regenerated by `run_all.py`; JSON artifacts remain the source of truth.
